# HostTemplate

工站上位机。连接 PLC，按流程字做进站、测试和出站，在主界面看当前状态，并在本机修改配置。工站配置和程序版本都从本线的 HTTP 服务获取。

## 能做什么

- 主界面显示工站名称、流程字、条码、托盘、轨迹、良品和不良件数，以及程序报警。顶栏有 PLC、MES、报警、运行四盏灯。
- 「实时数据」和「运行日志」两个页签。实时页显示当前这一件，画面由配置里的测试类型决定。类型为「默认」、空白或未登记时，使用内置页面。
- 顶栏在日间和夜间之间切换，选择写入配置，下次启动保持。
- 底栏「软键盘」打开 Windows 屏幕键盘。
- 「系统配置」修改工站参数、PLC 连接和地址、MES 接口。保存后马上生效。这里也可以打开或关闭自动更新、开机自启。
- 工站配置和日志放在工控机自己的目录里（默认 `%ProgramData%\HostTemplate\config` 和 `Logs`），不跟程序版本目录放在一起。本机没有配置时，先向本线服务要；服务也没有，再用程序里的模板。服务地址留空时可以离线打开。
- 「获取远端配置」会先询问是否覆盖本机文件。取消则不修改本机文件。确认后，用服务上的配置包覆盖本机同名文件；包里带有 `users.xml` 时一并覆盖。
- 「程序更新」列出服务上的全部版本，可以选择安装，也可以选择旧版本回退。工站空闲时才替换程序并重启：流程字是等待进站，没有产品在测，也没有步骤正在执行。
- 系统配置里打开「自动更新」后，只在目标版本比当前新时后台下载，下载之后等空闲才安装。
- 登录默认关闭。打开后按操作员、工程师、管理员区分权限。
- 打开「开机自启」后，当前用户登录 Windows 时自动启动本程序。每次启动都会写入开始菜单快捷方式；任务栏上还没有指向本程序的快捷方式时，再尝试钉住。

## 下载

发布包在 GitHub Releases：

https://github.com/gouhongfei258/hosttemplate/releases

每个版本有这些附件：

| 文件 | 用途 |
|---|---|
| `HostTemplate-<版本>.zip` | 解压后运行的程序目录 |
| `HostTemplate-<版本>-full.nupkg` | 交给本线后端的 Velopack 全量包 |
| `releases.win.json` | 和 nupkg 一起交给后端的版本索引 |

在工控机上使用 zip：解压后进入该版本目录，运行里面的 `HostTemplate.exe`。nupkg 是给后端的安装包，不要解到程序目录。

## 第一次运行

1. 双击 `HostTemplate.exe`。同一台机器上已经有一个实例时，会提示「程序已经在运行。」
2. 程序旁边如果还没有 `bootstrap.xml`，会按 `%ProgramData%\HostTemplate` 生成一份。工站配置和日志都在这个目录里。
3. 要连本线服务时，用文本编辑器改程序旁边的 `bootstrap.xml`：
   - `ServiceBaseUrl`：例如 `http://10.0.0.8:5080`。留空则只使用本机配置。
   - `StationId`：向服务要配置和版本时用的工站编号。已有 `app.xml` 时留空则用工站号。本机还没有配置、又要在启动时向服务拉取，这里必须填写。
   - `ServiceToken`：服务开了令牌才填。
4. 本机还没有 `app.xml`、`plc.xml`、`api.xml` 时，程序会向服务要。服务没有，就用自带模板生成。

程序旁边的 `bootstrap.default.xml` 是样例。启动读取或生成的是 `bootstrap.xml`，不读取这份样例。

## 现场操作

| 做什么 | 怎么做 |
|---|---|
| 看当前这一件 | 「实时数据」页 |
| 看运行日志 | 「运行日志」页 |
| 开始或停止监控 | 底栏「开始监控」「停止监控」。开始后按 PLC 流程字推进 |
| 把流程字拉回等待进站 | 「复位流程」 |
| 看报警 | 身份条下面的报警条。没有程序报警时显示「无程序报警」。出现新报警时会切到「实时数据」 |
| 切换日间或夜间 | 顶栏按钮。夜间界面下按钮写「日间」，日间界面下写「夜间」 |
| 打开屏幕键盘 | 底栏「软键盘」。优先系统自带的 `osk.exe`，没有时用触摸键盘 |
| 改配置 | 「系统配置」。PLC 页可以先「连接测试」，再「保存并生效」 |
| 打开配置所在的文件夹 | 配置页里的「打开配置目录」 |
| 用服务上的配置覆盖本机 | 「获取远端配置」。确认后才覆盖包里的 `app.xml`、`plc.xml`、`api.xml`，以及包里带有的 `users.xml` |
| 更新或回退程序 | 「程序更新」，选一个版本后点「安装此版本」。不空闲时会等空闲再装 |
| 自动更新、开机自启 | 「系统配置」里的对应开关 |
| 账号 | 默认不用登录。「账号管理」可以提前建账号。启用登录后，首次账号是 `admin` / `admin123`。登录后弹出修改密码，可以「稍后再说」 |
| 开始菜单和任务栏 | 启动时写入开始菜单快捷方式。任务栏上还没有指向本程序的快捷方式时，会再请求系统钉住。Windows 11 24H2 及以后，系统不接受程序自己静默钉住任务栏；开始菜单里的 HostTemplate 可以右键钉一次。钉不住不影响程序启动 |

窗口标题和右下角是当前程序版本。

只是把 zip 解压来运行、没有用 Velopack 安装时，「程序更新」会说明现在不能替换文件。

开发和扩展见 [开发手册](docs/开发手册.md)。
